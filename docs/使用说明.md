# desktop-calendar 使用说明

写给不用命令行、也不想看代码的人。跟着编号一步一步做就行。

---

## 一、第一次打开

1. 找到 `desktop-calendar.exe` 这个文件（如果是从源码构建的，它在 `build\` 文件夹里）。
2. **双击**它。
3. 屏幕上会出现一个 1180×780 的日历窗口，左边是整月日历，右边是当天的日程列表，底部一条状态栏。

不需要安装，不会往系统目录里塞东西，也不需要管理员权限。想换个地方放，直接把 exe 复制走就行（数据不在 exe 旁边，见第六节）。

窗口没有边框是正常的设计，顶部那条是自绘标题栏：

- **拖动窗口**：按住标题栏空白处拖。
- **关闭窗口**：点右上角 `×`。注意——它不会退出程序，只是收进托盘（见第五节）。
- **改变大小**：拖右下角。

## 二、看懂这个界面

窗口默认 1180×780，最小可以缩到 1040×700。左边是月历卡，右边是日程卡，**两张独立的卡片**，中间留了一道缝，各自带阴影——它们是两件事，别把它们当一整块。

**顶部**

- 左上角是品牌标记（蓝色方块 + 白色日历页 + 日期数字），右边是月份标题。
- 中间 `‹` `›` 翻月，`今天` 一键回到本月。
- 最右是 `—`（收进托盘）和 `×`（也是收进托盘，见第五节）。

**左侧月历卡**

- 一排七列，就是周一到周日。**一周从周一开始**，不是周日。
- 日期格用**色块**区分：本月是浅灰蓝，非本月更淡，今天整格偏蓝，选中的那天是白底 + 2px 蓝环，鼠标划过会亮一档。格子之间不画线，靠色块本身分界。
- 你点中的那一天，右边列表就跟着换成那一天的内容。
- 每格最多显示 2 条日程，左边一道彩色竖条 + 标题。超过 2 条就显示 `+2`、`+3`，表示还有几条没显示。
- **切换月份**：在日历上滚鼠标滚轮，或者点 `‹` `›`。

**右侧日程卡**

- 最上面是你选中的那天日期。
- 下面是「共 3 项 / 已完成 1」这样的统计。
- 再往下是这天的日程列表：一个小圆圈（勾选完成用）、时间、标题、左边的彩色条。
- 列表下面是**每日提示**卡：有逾期或没做完的日程时，它会直接告诉你还差几项；都做完了就换一条随机小提示。右上角 `换一条` 可以换（只在本次运行里换，不写入数据）。
- 最下面 `+ 新建日程` 按钮。

**底部状态栏**

从左到右：今天的完成进度、开机自启开关、明暗主题切换、最小化到托盘。

## 三、新建一条日程

**方法一（最快）**：在左边日历上**双击**你想安排的那一天。

**方法二**：点选那一天，再点右边 `+ 新建日程`。

弹出的窗口里填这几项：

1. **标题** —— 必填。「交房租」「给妈打电话」随便写。
2. **日期** —— 形如 `2026-03-15`。填错了可以用旁边的 `‹` `›` 按钮一天一天调。
3. **时间** —— 形如 `09:30`，24 小时制。**这个时间就是提醒你的时间**。
4. **重复** —— 下拉选：`单次` / `每天` / `每周` / `每月`。默认单次。
   - 选重复以后，会多出「重复至某日」这个可选项。**不填就是一直重复下去**；填了就在那一天（含当天）之后自动停止。
   - 选 `每周` 时，下面会多出一行「重复日」：`一 二 三 四 五 六 日` 七个按钮，**点哪几个就哪几天提醒**，可以多选。比如只点 `一` `三` `五`，就是每周一、三、五各提醒一次。
   - 新建时默认只点亮起始日期那天的星期几；**最后一个点亮的按钮点不掉**（至少保留一天，否则这条重复就没有意义了）。
5. **颜色** —— 六个彩色圆点挑一个。纯粹是为了让日历一眼能区分，比如工作用蓝色、家里事用绿色。
6. **备注** —— 想写多长写多长，提醒卡片上不会显示，但编辑的时候看得到。

填完点 `保存`，日历上立刻就能看到。

**改或删**：双击右边列表里的那条日程，重新编辑；不想要了就在编辑窗口里删掉。

**重复日程怎么算日子**（怕你踩坑，说清楚）：

| 选了 | 从哪天开始提醒 |
|---|---|
| 每天 | 起始日期那天起，天天提醒 |
| 每周 | 默认跟起始日期同一个星期几（起始日是周三就每周三）；如果在上面的「重复日」里点了别的星期几，就按你点的那些天提醒 |
| 每月 | 跟起始日期同一个「日」，比如起始日是 15 号，就每月 15 号 |

如果选的是「每月 31 号」，碰上没有 31 号的月份（2、4、6、9、11 月），会**自动挪到那个月的最后一天**提醒你，不会漏。

## 四、提醒是怎么来的

**触发方式**：程序在自己内部每 30 秒看一眼有没有到点的日程。所以只要程序在跑（哪怕收进了托盘），提醒就正常走。

**到点时你会看到**：

1. 屏幕**右下角**弹出一张小卡片，从下往上淡入。
2. 这张卡片**一直在最上层**，不会被别的窗口盖住；但它**不进任务栏**，不会在你切换窗口时碍事。
3. 卡片左边有一道彩色竖条——就是你当初选的那个分类颜色。
4. 卡片上是日程标题、时间，以及 `今天` 或 `已逾期` 的标签。
5. 同时，右下角托盘里的日历图标会**闪烁**，并弹一个气泡提示。

**卡片上三个按钮**

| 按钮 | 效果 |
|---|---|
| `完成` | 记这一次为已完成，卡片消失。重复日程只完成这一次，下次照常提醒。 |
| `+10 分钟` | 十分钟后再提醒我一遍。适合「现在正忙」。 |
| `今天忽略` | 今天不再提醒这一条，明天照常。适合「这事今天不做了」。 |

**逾期会追**：如果一条日程到点后过了 30 分钟你还没处理（没完成、没稍后、没忽略），卡片会再弹一次，这次标签写着 `已逾期`，提醒你它真的过时间了。

**不想让它太吵**：见下面的「怎样让提醒更凶 / 更安静」。

## 五、收起窗口、退出程序

**收起（推荐日常用法）**

点 `×`，或者点状态栏的托盘按钮。窗口消失，程序还在后台跑，提醒照常。

**调出来**

- **双击**右下角托盘里的日历图标。
- 或者**右键**那个图标，选 `打开日历`。

**托盘图标里有什么**

右键点托盘图标，菜单是：

- `打开日历` —— 回到主窗口
- `今日待办` —— 菜单上直接显示今天还有几项没做，点一下回主窗口看
- `开机自启` —— 带勾选，在这里也能开关
- `退出` —— 真正退出程序

**退出程序请走托盘菜单的「退出」**。点 `×` 只是藏起来——这是故意的，免得你误关就收不到提醒。

## 六、我的日程存在哪？会不会被上传？

存在这一个文件里：

```
%APPDATA%\DesktopCalendar\data.json
```

**怎么打开这个位置**：

1. 按键盘 `Win + R`，打开「运行」。
2. 输入 `%APPDATA%\DesktopCalendar`，回车。
3. 里面那个 `data.json` 就是你的全部日程。

它是普通文本文件，双击用记事本就能看（能看懂，但**别手改**，改坏了程序读不出来）。

- **备份**：把 `data.json` 复制一份放别的地方就行。
- **换电脑 / 迁移**：把 `data.json` 复制到新电脑的同一个位置。
- **关于隐私**：这个程序**不联网**，没有任何上传、同步、统计行为，也不装任何第三方组件。你的日程只在这台电脑的这个文件里。

## 七、如何设置开机自启

有两个入口，效果完全一样，开一个就行。

**入口一：底部状态栏**

主窗口最下面那条状态栏里，有一个开机自启的开关，点一下变成开启状态。

**入口二：托盘菜单**

右键托盘图标 → `开机自启`，让前面出现勾。

**设置之后会发生什么**

下次开机登录 Windows 时，程序会**静默启动**：托盘图标出现在右下角，提醒功能已经在工作，但**主窗口不会自动弹出来**打扰你。想用就双击托盘图标。

**这个开关做了什么（说人话版）**

它在 Windows 的「当前用户启动项」里加了一条记录（位置是注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，名字叫 `DesktopCalendar`），内容是程序的完整路径加上 `--silent` 参数。因为只写当前用户这一层，所以**不需要管理员权限**，也不会弹 UAC 授权框。

**怎么确认真的开了**

按 `Ctrl + Shift + Esc` 打开任务管理器 → 切到「启动」标签页 → 找 `DesktopCalendar`，状态应该是「已启用」。

**想彻底关掉**

托盘菜单里取消那个勾，或者任务管理器「启动」标签页里右键禁用。两种都行。

## 八、如何让提醒更凶（或者更安静）

程序自己的提醒强度是固定的：**置顶卡片 + 托盘闪烁 + 气泡 + 逾期 30 分钟再提醒一次**。它不会放声音、不会全屏、不会震动——这些它不做。但你可以用下面这些办法把它调得更难忽略或更安静。

**想让提醒更难忽略**

1. **别急着点掉卡片**。让它留在屏幕上，它一直在最上层，你干活时也会看到。
2. **用「+10 分钟」而不是「今天忽略」**。点「今天忽略」等于放弃今天这条提醒；点「+10 分钟」它十分钟后还会再来一次，可以连着点，等于一直催你。
3. **把时间设在你确实坐在电脑前的时刻**。提醒只在你电脑上、程序运行时才响，设个「明早 7 点」而你 8 点才开机，是收不到的。
4. **别让电脑睡过去**。Windows 休眠 / 关机期间程序没在跑，那段时间的提醒不会补发。
5. **打开 Windows 的通知声音**。「设置 → 系统 → 通知」，确认通知总开关是开的、声音是开的。托盘气泡的声音由系统控制。
6. **关掉「专注助手 / 勿扰模式」**。它们会把气泡和图标闪烁整体压掉，你会以为程序没工作。
7. **让托盘图标常驻可见**。Win11 默认把新图标塞进 `^` 折叠区，图标闪了你也看不见。右键任务栏 → 任务栏设置 → 其他系统托盘图标 → 把 `DesktopCalendar` 打开（或者在折叠区里把它拖到任务栏上）。
8. **重要的事多建一条**。比如「交房租」既建 15 号也建 16 号，或者同一天建 09:00 和 09:30 两条，反正不用花钱。

**想让提醒更安静**

1. 弹出时点 `完成`（真做完了）或 `今天忽略`（今天不想管）。
2. 不常用的日程把重复改成「单次」，或者干脆删掉。
3. 需要长时间不被打扰时，用 Windows 的「专注助手」压掉气泡——但要记得回头看一眼侧栏的今日待办。

## 九、常见小问题

**窗口是直角的，不是圆角**

正常。圆角是 Win11 系统级特性，Win10 没有，程序会自动跳过。功能一点不受影响。

**杀毒软件提示有风险**

自编译、没有数字签名的小程序常被误报。程序不联网、不上传，介意的话可以看源码或自己重新编译一遍。

**托盘里找不到图标**

被 Win11 折叠进 `^` 里了。点 `^` 展开看看，或者按上面第八节的办法让它常驻。

**点了 `×` 之后程序好像没了**

没没，它在托盘里。双击托盘图标就回来了。

**不小心双击了两次 exe**

程序是单实例的，第二个只会把已经开着的那个窗口叫出来，不会开两个，数据也不会打架。

## 十、这个程序不做什么

- 不联网、不云同步、不跨设备
- 不导入导出 `.ics`，不跟系统日历或手机日历互通
- 不用 Windows 通知中心那种原生通知（提醒卡片是程序自己画的窗口）
- 没有农历、节假日、纪念日倒数
- 没有标签、搜索、统计图表

它就是个「打开就能写、到点会叫你」的小日历。想要更多功能，源码在仓库里，改就是了。
